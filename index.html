PLEASE READ

Know what a public inbox means

Inbox access is based on the address. The API request is made to egmail.me/<address>. It does not ask this page for a password, and anyone who knows an address may be able to request its messages.

Saved addresses stay on this device. This page stores only your saved email addresses and preferences in this browser's local storage. It does not store message bodies or provide account login, cloud backup, or automatic cross-browser sync.

Use disposable inboxes carefully. Don’t use them for banking, private communications, account recovery, or any account where a public mailbox could put you at risk. Use the export/import controls to move saved addresses manually; that still does not make the inbox private.
